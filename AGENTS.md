# HoloNight File Browser

Read CONTRIBUTING.md. This independent provider owns shared browsing, selection,
search, storage browsing and preview primitives. Keep application settings, commands,
navigation policy and window composition in consumers. Native path bytes identify
entries; display strings do not.

Preserve the HolonightFileBrowser package, Core/Quick targets and Holonight.FileBrowser
QML import. Keep optional dependencies out of Core. Verify installed C++/QML consumers
and Core-only builds. System installation and ownership transfer belong to the umbrella.
Use Conventional Commits. Publication and umbrella pin updates require authorization.
