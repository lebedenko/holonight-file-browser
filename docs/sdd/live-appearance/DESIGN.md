# Live appearance propagation

Coordinated contract and acceptance: [umbrella design](../../../../docs/initiatives/live-appearance/DESIGN.md).

Quick consumes installed Qt Icons. Parse revision query metadata separately from candidate chains, invalidate cached hits/misses by appearance context, synchronize the engine appearance reader before a new cache generation, and retain physical sizing and bounded cost. Default listing/preview URLs bind to HnAppearance.revision; custom providers retain their URLs. Core does not gain Qt Quick or theme dependencies. Verify installed Core and Quick consumers.
